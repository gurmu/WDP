## The one-paragraph version

E1 set out to prove that OpenSharing can be perimeter-controlled through
Gravitee and scoped through Unity Catalog, and it largely can. What the
week actually produced, though, is more valuable than a green column:
**two controls that the documentation described as working, and that were
not.** The route table in §2.3.2 was a documentation allow-list that
nothing enforced, so the AI route forwarded unlisted paths into the
workspace REST API — found, fixed on that route, still open for two
others. And a *narrowed* entitlement predicate did not reach a live
consumer within ten minutes while every provider-side check reported the
reduction in force — which means **editing a view is not a working
revocation mechanism**, and the CONOPS currently implies it is. Both were
found by tests that insisted on observing each control *absent* before
believing it present. That one habit is the most transferable thing this
epic produced, and it is the subject of the single procedural
recommendation in note 01.
